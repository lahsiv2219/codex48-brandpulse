## ⚡ Two-Pass Hybrid AI Architecture

BrandPulse AI combines the deterministic precision of rule-based systems with the contextual reasoning of modern language models through our signature **Two-Pass Hybrid AI Architecture**:

```
                              ┌─────────────────────────┐
                              │    Submitted Draft      │
                              └────────────┬────────────┘
                                           │
                    ┌──────────────────────┴──────────────────────┐
                    ▼                                             ▼
        ┌───────────────────────┐                     ┌───────────────────────┐
        │        PASS 1         │                     │        PASS 2         │
        │  Deterministic Engine │                     │  Semantic Context LLM │
        ├───────────────────────┤                     ├───────────────────────┤
        │ • Sub-millisecond     │                     │ • Tone & nuance audit │
        │ • Regex pattern match │                     │ • Hallucination check │
        │ • Forbidden terms     │                     │ • Fact verification   │
        │ • Absolute claims     │                     │ • Policy citations    │
        └───────────┬───────────┘                     └───────────┬───────────┘
                    │                                             │
                    └──────────────────────┬──────────────────────┘
                                           ▼
                              ┌─────────────────────────┐
                              │  Consolidated Findings  │
                              │  & One-Click Rewrites   │
                              └─────────────────────────┘
```

### 1. Pass 1: Deterministic Engine (Zero-Latency Guarantee)
- Instantaneous regex and keyword boundary matching.
- Flags critical terms, absolute guarantees (`100% guaranteed`, `no risk`), unverified superlatives (`#1`, `best in the world`), and pressure tactics.
- Functions entirely client-side/locally with zero external network dependencies, ensuring 100% platform availability.

### 2. Pass 2: Semantic AI & Contextual Reasoner
- Context-aware evaluation against brand tone parameters (Empathetic, Confident, Human, Transparent).
- Cross-references assertions against the **Brand Vault** approved claims database to prevent brand drift and fabricated performance metrics.
- Emits explainable issue cards containing the exact policy citation, rationale, and recommended drop-in rewrite.

## 🚀 Key Platform Features

- **🔍 Explainable Scanner & Issue Cards**: Flags critical violations and advisory recommendations. Creators can review exact rule citations and accept one-click rewrites directly into their drafts.
- **🎨 Visual Asset & WCAG Accessibility Checker**: Upload banner images, creatives, or UI screenshots to automatically extract hex palette distributions and evaluate WCAG 2.1 AA/AAA contrast ratios against light and dark backdrops.
- **📚 Brand Vault**: The centralized corporate truth repository containing active rules, forbidden terminology, brand color palettes, and certified claims.
- **🔄 Multi-Role Approval Workflow**: Guided state pipeline transitioning drafts from *Draft → AI Scan → Revision → Manager Review → Legal Review → Brand Approval → Scheduled → Published*.
- **🔒 Tamper-Evident SHA-256 Audit Trail**: Every workflow progression and editorial decision is cryptographically chained with SHA-256 hashes (`GENESIS` $\rightarrow$ $H_n$). Built-in verification can instantly detect any database alteration or unauthorized tampering.
- **📊 Real-Time Compliance Analytics**: Visualizes 30-day recurring violations, areas where guidelines require clarification, and 8-week brand score trend trajectories.

## 🏁 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/)

### Installation & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/lahsiv2219/BrandPulse-AI.git
   cd BrandPulse-AI
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)
